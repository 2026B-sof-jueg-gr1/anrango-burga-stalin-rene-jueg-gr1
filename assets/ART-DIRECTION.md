# Arte de Órbita: Contrapunto

`contrapunto-keyart.png` es una ilustración creada para este proyecto con la herramienta integrada `image_gen` de Codex. No se utilizó la alternativa CLI/API. La imagen se conserva completa; los encuadres de menú, retratos y escenas se realizan con CSS.

Dirección: novela gráfica espacial, Sira y Elia a ambos lados de una señal musical; índigo y verde para la llamada, cobre para la respuesta. El mapa, los motivos narrativos y sus animaciones son elementos de código independientes de la ilustración.
